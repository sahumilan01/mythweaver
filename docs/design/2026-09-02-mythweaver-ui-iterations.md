# MythWeaver UI improvement loops

## Loop 1: make the consent model scannable

The welcome panel explained the idea in prose, but the human and agent roles were easy to miss. Added a compact three-part flow, `You draw → Agent proposes → You decide`, so the product's safety boundary reads before either call to action. Kept the existing editorial layout and used the coral accent only for the role icons.

## Loop 2: separate proposal from commitment

The review card made accept and discard clear, but the staged state was buried in a small footer. Moved that distinction beside the proposal title as a persistent `Not in story` status. This makes provenance visible at the point of judgment and removes the redundant footer copy.
